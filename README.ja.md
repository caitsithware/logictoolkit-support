# Logic Toolkit サポート

[English](README.md) | **日本語**

Unityアセット「**Logic Toolkit**」の公式サポート窓口です。  
**Logic Toolkit**についての詳細は <https://logictoolkit.caitsithware.com/ja> を参照してください。  
このリポジトリにはソースコードは含まれていません。質問、不具合報告は **Discussions** で受け付けています。

## 質問・ご要望はこちら

👉 [Discussionsを開く](https://github.com/caitsithware/logictoolkit-support/discussions)

| カテゴリ | 用途 |
|---|---|
| Q&A | 使い方の質問、困りごと |
| Bug Reports | 動作がおかしい場合 |
| Announcements | アップデートやメンテナンス情報(運営からの投稿のみ) |

投稿前に過去のDiscussionsを検索すると、すぐに解決することがあります。

## 投稿時のお願い

- 利用中の **バージョン** と **OS・環境** を書いてください
- 不具合は **再現手順**、**期待した動作**、**実際の動作** を書いてください
- スクリーンショットは歓迎です

### ⚠️ 機密情報は書かないでください

Discussionsの投稿は **誰でも閲覧できます**。次の情報は投稿しないでください。

- ライセンスキー、パスワード、APIキー、トークン
- 個人情報、顧客データ
- スクリーンショットに含まれる上記の情報(投稿前に隠してください)

## 個別対応が必要な場合

ライセンス、契約、請求、機密情報が関わるお問い合わせは、Discussionsではなく下記までご連絡ください。

[お問い合わせ](https://caitsithware.com/ja/contact-us/)

## 対応方針

- 回答までお時間をいただくことがあります。
- すべてのご要望にお応えできるとは限りませんが、今後の開発の参考にさせていただきます
- 誹謗中傷や宣伝目的の投稿は、削除する場合があります
